# PRD: 김종덕 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 김종덕의 역량과 작업물을 소개하는 개인 프로필(포트폴리오) 웹사이트 |
| 대상 방문자 | 채용 담당자, 협업/외주 의뢰자, 개발자 커뮤니티 |
| 개발자 | 김종덕 |
| 연락처 | papasmf1@gmail.com |
| 주 개발 분야 | 바이브코딩, Python, HTML5 |

## 2. 목표

1. 방문자가 10초 안에 "누구이며 무엇을 하는 개발자인지" 파악할 수 있다.
2. 주력 분야(바이브코딩, Python, HTML5)와 대표 프로젝트를 한눈에 보여준다.
3. 이메일 문의로 자연스럽게 이어지는 연락 동선을 제공한다.

### 성공 지표
- 첫 화면에서 이름, 직군, 연락 버튼이 스크롤 없이 보인다.
- 모바일/데스크톱 모두 레이아웃이 깨지지 않는다.
- Lighthouse 성능/접근성 점수 90 이상.

## 3. 범위

### 포함 (In Scope)
- 단일 페이지(One-page) 정적 웹사이트
- 반응형 디자인 (모바일 / 태블릿 / 데스크톱)
- 프로젝트 소개 및 연락 섹션

### 제외 (Out of Scope)
- 로그인, 회원 기능
- 백엔드 서버, 데이터베이스
- 블로그 CMS (필요 시 2차 개발)

## 4. 페이지 구성

| 섹션 | 내용 |
|---|---|
| Header / Nav | 로고(이름), 앵커 메뉴: About · Skills · Projects · Contact |
| Hero | 이름 "김종덕", 한 줄 소개(바이브코딩 · Python · HTML5 개발자), Contact 버튼 |
| About | 자기소개, 개발 철학, 작업 방식(AI와 협업하는 바이브코딩) |
| Skills | 바이브코딩, Python, HTML5(+CSS3, JavaScript) 카드/레벨 표시 |
| Projects | 대표 프로젝트 카드 3~6개 (제목, 설명, 사용 기술, 링크) |
| Contact | 이메일 `papasmf1@gmail.com` (mailto 링크), 복사 버튼 |
| Footer | 저작권 표기 |

## 5. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| F-01 | 상단 고정 내비게이션, 클릭 시 해당 섹션으로 부드럽게 스크롤 | 필수 |
| F-02 | 스킬 항목 표시 (바이브코딩, Python, HTML5) | 필수 |
| F-03 | 프로젝트 카드 목록 (데이터는 JS 배열/JSON으로 관리) | 필수 |
| F-04 | 이메일 링크(mailto) 및 클립보드 복사 버튼 | 필수 |
| F-05 | 반응형 레이아웃 (모바일 우선) | 필수 |
| F-06 | 다크/라이트 테마 전환 | 선택 |
| F-07 | 스크롤 시 섹션 등장 애니메이션 | 선택 |

## 6. 비기능 요구사항

- **성능:** 외부 라이브러리 최소화, 이미지 최적화(WebP), 초기 로드 1초대.
- **접근성:** 시맨틱 태그(`header`, `nav`, `main`, `section`, `footer`), 대체 텍스트, 충분한 색 대비, 키보드 탐색 지원.
- **SEO:** `title`, `meta description`, Open Graph 태그 설정.
- **호환성:** 최신 Chrome, Edge, Safari, Firefox.

## 7. 기술 스택

- HTML5, CSS3(Flexbox/Grid, CSS 변수), Vanilla JavaScript
- 프레임워크 없이 정적 파일로 구성, GitHub Pages 등으로 배포 가능

## 8. 디자인 가이드

- 톤: 깔끔하고 현대적인 개발자 감성, 여백 넉넉하게
- 컬러: 어두운 배경(`#0f1220`) + 포인트 컬러(`#5c7cfa`) 기본, 라이트 테마 지원
- 폰트: 본문 Pretendard 또는 시스템 폰트, 코드/강조는 모노스페이스
- 레이아웃: 최대 폭 1100px 중앙 정렬, 모바일 1열 → 데스크톱 2~3열
